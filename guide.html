Claude Code Skill

输入一个主题
拿到一份能直接讲的 HTML

Cobo Slides 是一个 Claude Code 技能。装好之后，你只要说清楚要讲什么、讲给谁， Claude 会问几个问题、和你确认大纲，然后产出一个零依赖的单文件 HTML —— 符合 Cobo 官网配色、每页锁定一屏、离线可用、能导出 PDF。

01这是什么

它不是一个程序，而是一套给 Claude 读的说明书：品牌规范、组件库、版式约束、JS 控制器实现。 Claude 每次生成前都会完整读一遍，所以你改了品牌色，下一份 deck 立刻跟着变。

产出
单个 .html

CSS / JS 全内联，只有 Google Fonts 走 CDN。丢给别人双击就能看。

约束
每页正好一屏

内容超了自动拆页，绝不滚动、绝不硬塞。

语言
中文优先

默认简体中文，除非你给的是别的语言。

02安装

克隆到 Claude Code 的技能目录即可，无需重启，Claude 会自动识别。

git clone https://github.com/beyalee/cobo-ppt-html-skill ~/.claude/skills/cobo-slides
注意 仓库原名 cobo-slides，现已更名为 cobo-ppt-html-skill。旧地址目前靠 GitHub 重定向仍可 clone， 但建议直接用新地址。本地目录名仍用 cobo-slides —— 技能名由目录名决定。

更新到最新版

git -C ~/.claude/skills/cobo-slides pull

03三种用法

① 只给主题，让它全写

最省事。Claude 会先问受众、页数、章节，再动手。

帮我做一个 Cobo MPC 钱包的客户演示

② 给大纲或全文，只要排版

你已经想清楚讲什么，把要点贴给它，它负责版式与视觉。

按这个大纲做一份 deck，面向合规团队：
1. 监管背景  2. 规则要求  3. 操作流程  4. 合规联动

③ 把现有 PDF / PPT 转成 HTML

Claude 会把 PDF 逐页转图读取、或用 python-pptx 抽取文字，再按品牌规范重排。

把这份 PPT 转成 HTML @产品介绍.pdf
转换是重排不是复刻：它保留内容与结构，但版式会套用 Cobo 规范。 想保留原样请直接用原文件。

04Claude 的四个阶段

  1. 问需求 —— 主题、受众、内容来源、页数、章节，一次性问完。
  2. 出大纲 —— 给出分章与页数分配，等你确认再往下走。这一步值得认真看：大纲的顶层章节会原样变成导航条的 Tab。
  3. 生成 HTML —— 读取品牌规范与模板，产出单文件。
  4. 交付 —— 打开预览，并问你要不要导出 PDF 或部署成公网链接。
阶段 2 的大纲限制在 4–6 个章节。不是排版洁癖 —— 章节数直接决定导航条可不可用，见下一节。

06导航条规则

顶部导航条给的是整场演讲的结构，不是页码索引。它永远只有 4–6 个章节 Tab，硬上限 7 个 —— 哪怕你的 deck 有 23 页。

每个 Tab 用 data-start / data-end 覆盖一段页码区间， 区间必须无缝隙、无重叠地铺满所有页。名字是内容，编号只负责排序 —— 窄屏空间不够时藏的是编号，永远不是名字。

5 个字讲不清的章节，说明这章切得太粗 —— 该拆或重切，而不是起个含糊的名字。

08导出与部署

导出 PDF

用 Playwright 逐页截取，首次运行会自动装依赖（需要 Node.js）。

bash ~/.claude/skills/cobo-slides/scripts/export-pdf.sh my-deck.html # 可选：追加输出路径

部署成公网链接

走 Vercel，需先 npx vercel login。

bash ~/.claude/skills/cobo-slides/scripts/deploy.sh my-deck.html
提醒 部署会把内容发布到公网。含客户名称、报价、未公开路线图的 deck， 请先确认可以外发。

09文件结构

cobo-slides/ ├── SKILL.md # 主流程：四个阶段 + 导航条规则 ├── COBO_BRAND.md # 品牌规范：CSS 变量 + 组件库 + 图标 + 产品词汇表 ├── viewport-base.css # 强制响应式基础样式（必须整段嵌入） ├── html-template.md # JS 控制器完整实现 + 踩坑对照表 ├── animation-patterns.md # 动画片段参考 ├── guide.html # 本文档 └── scripts/ ├── export-pdf.sh # 导出 PDF └── deploy.sh # 部署到 Vercel

10定制

改品牌色 / 加组件

编辑 COBO_BRAND.md。Claude 每次生成前都会读最新版本，改完立即生效。

改流程 / 改规则

编辑 SKILL.md。比如想调整章节数上限、密度限制或提问方式。

改完记得提交，团队其他人 git pull 就同步了。

11故障排查

下面几个是这套模板真实踩过的坑，修复已写进 html-template.md 与 viewport-base.css。自己改代码时留意别改回去。

症状原因修法
页码和 Tab 变了，页面不动 body 上的 overflow-x:hidden 按规范把 overflow-y 强制成 auto，body 成了第二个滚动容器 overflow 和 height:100% 只放 html
只有第一页，后面全没了 body{height:100%} 把内容裁到一屏 改 min-height:100%
内容左偏、出现横向滚动条 .slide{width:100vw} —— 100vw 含滚动条宽度 改 width:100%
导航高亮的不是当前页 IntersectionObserver 在滚动途中覆盖了 currentSlide navLock 标志位
停在两页中间 兜底逻辑按"是否到达"触发，打断了正常的平滑滚动 改成按"是否没动"触发
手机上导航只剩 01 02 03 窄屏把 .tn-ch-name 藏了 该藏的是 .tn-ch-num

自检两条

生成后在控制台跑一下，都为 true 才算过：

// 1. 每次跳转都精确停在页首
deck.goTo(5); // 等 2 秒后
window.scrollY === deck.slides[5].offsetTop

// 2. 没有横向溢出
document.documentElement.scrollWidth === document.documentElement.clientWidth
